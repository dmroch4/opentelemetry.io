O [OpenTelemetry Collector](/docs/collector/) é uma forma vendor-agnostic de
receber, processar e exportar dados de telemetria. Embora o Collector possa ser
usado em muitos lugares, esta documentação focará em como usar o Collector para
monitorar o Kubernetes e os serviços em execução nele. Para documentação mais
geral do Collector, como configuração e resolução de problemas, consulte
[Collector](/docs/collector/).
